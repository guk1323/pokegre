# 이베이 낙찰가 점검 러너

저쪽(PPT)이 낙찰가를 틀리게 줘서, **이베이 원문을 열어 맞대 본다.** 서버에서 이베이를 부르면
403이라 **사장님 크롬에서** 돈다.

## 왜 탭이 둘인가

이베이 탭은 우리 서버를 **못 부른다**(이베이 CSP의 `connect-src`가 막는다. 2026-08-16 실측:
`TypeError: Failed to fetch`). 그래서 pokegre.com 탭이 대신 부른다.

```
이베이 탭 ── postMessage ──▶ 다리 탭(pokegre.com) ── fetch ──▶ 우리 서버
 (매물을 읽는다)                 (서버와 이야기한다)
```

⚠️ **다리 탭에 열쇠(토큰)를 넣지 않는다.** 스크립트에 비밀을 적는 짓이고, 도구도 막는다.
   서버가 `sec-fetch-site: same-origin`으로 알아본다(v532). 그 값은 **브라우저가 직접 넣고
   스크립트가 못 바꾸는** 값이라 남의 사이트가 흉내 낼 수 없다.

## 띄우는 차례

1. 크롬에서 이베이 매물 아무 페이지나 연다.
2. 그 탭에서 `window.__b = window.open('https://pokegre.com/?bridge=1')`
   — 새 탭이 크롬 탭 그룹에 들어와 주입할 수 있게 된다.
3. **새 탭**에 `bridge.js`를 넣는다.
4. **이베이 탭**에 `runner.js`를 넣는다. 맨 위 `급함`을 골라 둔다.

## 급함 차례 — 이대로 하나씩

| 급함 | 남은 것(2026-08-16) | 왜 |
|---|---|---|
| `p15` | 3,272 | 틀린 값의 90%가 $15. **절반쯤이 틀렸다** — 평균보다 140배 효율 |
| `헐값상위` | 22,934 | 등급 받은 카드가 $20 밑은 드물다 |
| `헐값` | 55,675 | 나머지 헐값 |
| `상위` | 153,611 | psa10·psa9·cgc10 — 틀리면 제일 눈에 띈다 |
| (빈 값) | 273,795 | **전부. 결국 여기까지 간다** |

⚠️ **거르는 게 아니라 순서다.** 마지막 칸에 조건이 없으므로 빠지는 것이 없다.
⚠️ 순서를 바꿔도 안 꼬인다 — 진행은 매물번호로 적히고 큐는 부를 때마다 새로 만든다.
⚠️ **`skip`은 쓰지 마라.** 순서에 기대는 값이라 급함을 바꾸면 엉뚱한 데를 가리킨다.

## 조심할 것

- **러너가 도는 동안 이베이를 따로 건드리지 마라.** 그래서 한 번 차단당했다.
- **이베이가 조인다.** 두 시간 돌린 직후 다시 돌리니 분당 233건 → **36건**으로 떨어지고
  못 읽음이 38%까지 올랐다. **하루 2~3시간씩 나눠 도는 편이 낫다.**
- 막힘이 연속 8번이면 러너가 스스로 멈춘다. 그러면 몇 시간 쉬어야 한다.
- 다 끝나면 `scripts/check-fix-outliers.mjs`로 고친 값이 이웃과 말이 되나 본다.
