# 플리마켓 카드 등급 기준 (초안 v1)

작성 2026-07-27 · **확정 전 초안입니다.**

판매자가 **스스로** 등급을 매기는 방식이라, 말이 애매하면 그대로 분쟁과 엉터리 시세가 됩니다.
그래서 이 문서는 "작은 흠"·"큰 흠" 같은 표현을 **전부 숫자와 부위로** 바꿔 놓았습니다.

참고한 곳: [카드러시](https://www.cardrush-pokemon.jp/page/5) (A·B·C·D를 쓰고 기준을 공개함),
[하레루야2](https://www.hareruya2.com/en/pages/card-condition), [TCGplayer](https://help.tcgplayer.com/hc/en-us/articles/26141121045143-Understanding-Card-Condition-Imperfections-A-Comprehensive-Guide).
스니커덩크는 A·B·C·D를 쓰지만 **각 등급의 뜻을 공개하지 않았습니다**(2026-07-27 확인). 그래서 우리가 정합니다.

---

## 0. 대원칙 세 가지

**① 헷갈리면 아래 등급으로.**
A인지 B인지 모르겠으면 B입니다. 이 규칙 하나가 분쟁의 대부분을 막습니다.

**② 등급은 "안 좋은 곳 하나"로 정해집니다.**
모서리가 완벽해도 표면에 흠이 있으면 표면 쪽 등급을 따릅니다. 평균이 아닙니다.

**③ 보는 방법을 통일합니다.**
슬리브를 벗기고, **밝은 실내조명 아래 팔 길이(약 50cm)에서 정면으로** 봅니다.
돋보기나 손전등을 비스듬히 비춰야만 보이는 것은 등급을 깎지 않습니다.

## 1. 등급에서 **빼는** 것

이걸 먼저 정해야 합니다. 안 그러면 멀쩡한 카드가 전부 C가 됩니다.

| 항목 | 처리 | 이유 |
|---|---|---|
| **휨** | 등급에 넣지 않음 | 습도 때문에 생겼다 사라집니다. 카드러시도 휜 카드를 원칙적으로 A로 봅니다. 단 **눌러도 안 펴지는 휨**은 C. |
| **센터링** | 등급에 넣지 않음 · **따로 표기** | 쓰다가 생긴 게 아니라 인쇄 개체차입니다. pokegre에 이미 센터링 도구가 있으니 매물에 센터링 수치를 따로 붙입니다. |
| **초기 흠** | A로 취급 | 공장에서부터 있던 은박 눌림·잘림 오차 등. 단 **정면에서 바로 보이면** B로 내립니다. |
| **먼지·지문** | 등급에 넣지 않음 | 닦으면 없어집니다. 다만 **사진 찍기 전에 닦아 주세요.** |

## 2. 판정 항목 네 가지

카드를 볼 때 이 네 곳만 봅니다.

1. **모서리** — 뾰족한 네 귀퉁이
2. **옆면** — 네 변의 테두리
3. **표면** — 앞뒤 그림면. 흠집·오염·광택 벗겨짐
4. **변형** — 접힘, 눌림, 찢어짐, 물 젖음

---

## 3. 등급표

### A — 거의 새것

| 항목 | 허용 범위 |
|---|---|
| 모서리 | **흰 까짐 없음.** 네 귀퉁이 모두 뾰족함 |
| 옆면 | 흰 점 **1mm 이하**가 **합계 2곳까지**. 그 이상이면 B |
| 표면 | 기울여야 보이는 잔흠만. **정면에서는 아무것도 안 보임** |
| 변형 | 없음 |

> 팩에서 막 꺼낸 카드, 또는 개봉 직후 바로 슬리브에 넣어 보관한 카드입니다.

### B — 잘 보관했지만 흔적이 있음

| 항목 | 허용 범위 |
|---|---|
| 모서리 | 흰 까짐 **1mm 이하**가 **2곳까지** |
| 옆면 | 흰 점이 여러 곳. 또는 **1mm 넘는 것이 2곳까지** |
| 표면 | 정면에서 보이는 잔흠 **2개까지**, 각각 **5mm 이하** |
| 변형 | 없음 |

> 수집용으로 사도 무리 없지만 완벽하진 않은 상태입니다.

### C — 눈에 띄게 사용감

| 항목 | 허용 범위 |
|---|---|
| 모서리 | 흰 까짐이 **3곳 이상**, 또는 **1mm 초과** |
| 옆면 | 테두리 전체가 하얗게 뜸 |
| 표면 | 정면에서 바로 보이는 흠, 오염, 광택 벗겨짐 |
| 변형 | **얕은 눌림까지만.** 접힘은 안 됨 |

> 플레이용입니다. 수집용으로는 권하지 않습니다.

### D — 손상

**아래 중 **하나라도** 해당하면 무조건 D입니다.** 다른 곳이 아무리 깨끗해도 D입니다.

- 접힘 (빛에 비춰 선이 보이는 것 포함)
- 찢어짐, 뜯김
- 물 젖음, 얼룩
- 코팅·은박 벗겨짐
- 낙서, 사인, 스티커 자국
- 눌러도 안 펴지는 휨

## 4. 등급별 필수 사진

**말로 우기는 걸 막는 유일한 방법입니다.** 사진이 빠지면 등록이 안 되게 합니다.

| 사진 | A | B | C · D |
|---|:---:|:---:|:---:|
| 앞면 전체 (정면, 슬리브 벗기고) | 필수 | 필수 | 필수 |
| 뒷면 전체 | 필수 | 필수 | 필수 |
| 빛 반사 사진 (표면 흠이 보이게 비스듬히) | 필수 | 필수 | 필수 |
| 모서리 근접 (네 귀퉁이가 보이게) | 필수 | 필수 | — |
| 결함 부위 근접 | — | 흠이 있으면 | 필수 |

**사진 규칙**

- 카드가 화면의 **70% 이상**을 채울 것
- **슬리브·탑로더를 벗기고** 찍을 것 (감정 카드는 예외)
- 다른 카드나 인터넷 사진을 쓰면 **이용 정지**

## 5. 감정 카드

감정 카드는 등급을 판매자가 매기지 않습니다. **감정사가 이미 매겼습니다.**

**등록할 때 반드시 넣는 것**

| 항목 | 내용 |
|---|---|
| 감정사 | PSA · BGS · CGC · ARS · 기타 |
| 등급 | PSA 10, BGS 9.5 같은 숫자 |
| **인증번호** | 라벨에 적힌 번호. **필수** |
| 라벨 사진 | 번호가 **읽히게** 찍은 사진. 필수 |
| 케이스 상태 | 깨짐·긁힘 있으면 표기 |

**인증번호를 필수로 받는 이유**는 나중에 감정사 공식 조회로 대조해서 **가짜를 걸러낼 수 있기 때문**입니다. 지금은 눈으로 확인하고, 나중에 자동 확인을 붙입니다.

**표기는 스니커덩크와 맞춥니다.** 그래야 우리 시세와 스니커덩크 시세를 나란히 놓고 볼 수 있습니다.

```
PSA10 · PSA9 · PSA8 이하
BGS10 BL · BGS10 GL · BGS9.5 · BGS9.5 이하
ARS10+ · ARS10 · ARS9 · ARS8 이하
기타 감정품
```

## 6. 시세로 쓸 때 규칙

이게 플리마켓을 만드는 **진짜 목적**이라 제일 중요합니다.

| 규칙 | 내용 |
|---|---|
| **등급을 절대 섞지 않음** | A 가격과 C 가격을 평균 내면 아무 의미가 없습니다. 등급별로 따로 냅니다 |
| **거래 성사분만** | 올려놓은 가격(호가)은 시세가 아닙니다. 실제로 팔린 것만 씁니다 |
| **최소 건수** | 같은 카드·같은 등급으로 **3건 이상** 모여야 시세로 표시합니다. 미만이면 "표본 부족" |
| **극단값 제외** | 평균에서 크게 벗어난 건은 뺍니다 (구체 기준은 데이터 쌓인 뒤 정함) |
| **신고 누적 판매자 제외** | 등급을 반복해서 부풀린 판매자의 거래는 시세에서 뺍니다 |
| **표기 방법** | "pokegre 회원 거래가"로 표시. 스니커덩크·이베이 시세와 **구분해서** 보여줍니다 |

## 7. 등급이 틀렸을 때

| 상황 | 처리 |
|---|---|
| 구매자가 등급 이의 제기 | 사진으로 판정. 등급이 실제보다 높았으면 **판매자 책임** |
| 1회 | 경고 |
| 2회 | 등록 제한 |
| 3회 | 이용 정지 + **그 판매자의 과거 거래를 시세에서 전부 제외** |

## 아직 안 정한 것 (사장님 결정 필요)

- [ ] **A 위에 등급을 하나 더 둘지** — 스니커덩크는 없습니다. 하레루야2는 `A` 하나로 두고 `+`/`-`로 나눕니다. 저는 **A~D 네 개로 단순하게** 가는 걸 권합니다. 처음부터 복잡하면 아무도 안 씁니다.
- [ ] **미개봉(팩·박스)도 취급할지** — 취급하면 등급이 아니라 "미개봉" 별도 항목이 필요합니다.
- [ ] **한글판·일본판·북미판 구분** — 같은 카드라도 판본이 다르면 시세가 완전히 다릅니다. 등록할 때 필수로 받아야 합니다.
- [ ] **거래 방식** — 직거래만인지, 택배 포함인지. 택배면 배송 중 손상 책임을 정해야 합니다.
- [ ] **통신판매중개 신고 문제** — 개인 간 거래를 중개하면 법적으로 확인할 게 있습니다. 별도로 정리가 필요합니다.
